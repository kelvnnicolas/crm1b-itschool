# CRM Escola de TI (MVP)

crm base inicial para modelagem de crms b2b de pequeno porte. 

Sistema de CRM e gestão focado em Escolas de Tecnologia.

## Funcionalidades
- Gestão de Contatos e Leads (Pipeline Kanban)
- Gestão de Cursos, Turmas, Alunos e Matrículas
- Controle Financeiro Básico
- Autenticação e Perfis (Admin, Comercial, Professor, Operacional)

## Stack Tecnológica
- **Frontend**: Next.js (App Router), React, Tailwind CSS, shadcn/ui.
- **Backend**: Server Actions e Supabase.
- **Banco de Dados**: PostgreSQL (via Supabase) com Row Level Security (RLS).
